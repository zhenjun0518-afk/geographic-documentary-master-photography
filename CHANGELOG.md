# Changelog

All notable changes to this project are documented here. Versions follow Semantic Versioning.

## [1.2.0] - 2026-09-09

### Added
- Built-in Maintainer / Upgrade Protocol in `SKILL.md`.
- Semantic-versioning rules for future AI-assisted Skill upgrades.
- Post-change validation and repository re-read requirements.
- `UPGRADE.md` with user update commands and maintainer request templates.
- Cross-platform local update helpers for macOS/Linux and Windows PowerShell.

### Changed
- Clarified that repository state is the source of truth during maintenance.
- Added explicit truthfulness rules: no claiming an upgrade, commit, release, or installation unless it actually occurred.

## [1.1.0] - 2026-09-09

### Added
- English-first executable Skill definition.
- English default README and Simplified Chinese README.
- English and Chinese triggers with automatic response-language matching.

## [1.0.0] - 2026-09-09

### Added
- Initial geographic documentary photography Skill.
- Landscape, wildlife, human geography, travel, expedition, urban, aerial, underwater, weather, and staged observational character modes.
- User-condition locking, batch-diversity rules, and natural-language prompt composition.
